# Plotzel art slots

Drop files here with these names (.png, .webp, .jpg, .jpeg or .svg with the same base
name also work). A missing file uses the built-in cartoon placeholder; no code change.
A production build must be re-run after adding files.

| File               | Size (CSS px)  | Where it shows                                                                    |
| ------------------ | -------------- | --------------------------------------------------------------------------------- |
| `cloud.png`        | 96 x 96        | the green "fart cloud" puff after every wrong row (transparent background)         |
| `mascot.png`       | 64 x 64, round | optional mascot face next to the message bubble, normal mood                        |
| `mascot-happy.png` | 64 x 64, round | mascot when the word is solved                                                    |
| `mascot-oops.png`  | 64 x 64, round | mascot right after a wrong row and when the word was not found                    |

Square images, subject centered; the mascot is clipped to a circle. Use about 2x the
size (e.g. 128 x 128) for sharp phones.
